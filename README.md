🚀 **Excited to Share My MERN Stack Project – ShopNest!** 🛍️

I'm happy to showcase **ShopNest**, a full-stack e-commerce web application that I built to strengthen my MERN Stack development skills.

### ✨ Key Features

✅ User Authentication (JWT)
✅ Product Listing & Search
✅ Shopping Cart
✅ Secure Checkout
✅ Razorpay Payment Integration (Test Mode)
✅ Order Management
✅ Admin Dashboard
✅ Product Management (Add, Edit, Delete)
✅ Cloudinary Image Upload
✅ Responsive UI

### 🛠️ Tech Stack

* React.js
* Redux Toolkit
* Node.js
* Express.js
* MongoDB
* JWT Authentication
* Cloudinary
* Razorpay
* Netlify (Frontend)
* Render (Backend)

This project helped me gain hands-on experience in building a complete e-commerce application, integrating APIs, handling authentication, managing state with Redux, and deploying a full-stack application.
